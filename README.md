# What's Next On — Entertainment Discovery

**A visual-first entertainment discovery website with a cinematic editorial feel.**

**Live site:** https://whatsnexton.com/  
**Designer portfolio:** https://brendanmmcnamara.com/

## Project overview

What's Next On explores how visual hierarchy, imagery, and responsive interface design can make entertainment content easier to explore. The project is presented here as a digital product and visual design portfolio case study.

## Design goals

- **Clear discovery:** Help people scan featured entertainment content and explore what interests them.
- **Editorial hierarchy:** Give featured content prominence while keeping supporting information easy to find.
- **Visual storytelling:** Use cinematic imagery, typography, and contrast to create an engaging brand experience.
- **Responsive design:** Maintain clarity and consistency across desktop and mobile layouts.
- **Repeatable patterns:** Build a recognizable design language across pages and components.

## UX and visual design approach

### 1. Information architecture

Structure content around discovery and navigation. Group related content and identify what should command attention first.

### 2. Visual direction

Develop a cohesive visual language through image selection, type hierarchy, spacing, and contrast, inspired by editorial and entertainment design.

### 3. Interface refinement

Review layout density, button and link emphasis, navigation clarity, and the consistency of common UI patterns.

### 4. Responsive considerations

Adapt content hierarchy, spacing, and presentation for smaller screens rather than simply shrinking desktop layouts.

These are the project's design objectives and approach. Formal research findings, usability testing data, and outcome metrics have not been published in this repository.
