# What's Next On — Entertainment Discovery

**A responsive entertainment-discovery experience focused on visual storytelling, content hierarchy, and intuitive browsing.**

[Explore the live website](https://whatsnexton.com/) · [View design portfolio](https://brendanmmcnamara.com/)

## Overview

What's Next On explores how editorial design and digital product thinking can make entertainment content easier to discover and browse. The project brings together a visual identity, content-led layouts, and a responsive web interface.

## Design goals

- **Discovery:** Make entertainment content approachable and easy to scan.
- **Hierarchy:** Establish clear relationships between featured content and supporting information.
- **Visual storytelling:** Use imagery, typography, and composition to create a cinematic feel.
- **Consistency:** Maintain a coherent interface across pages and screen sizes.
- **Responsiveness:** Adapt the experience for desktop and smaller screens.

## UX and visual design approach

### 01 — Content structure
Organize information around browsing and discovery, prioritizing featured content and clear navigation.

### 02 — Interface design
Develop a consistent visual language using typography, spacing, imagery, and reusable layout patterns.

### 03 — Responsive experience
Consider how content density, hierarchy, and navigation translate across viewport sizes.

### 04 — Implementation and iteration
Bring the interface into a working website, review the presentation in-browser, and refine the experience.
